# NevvaVisuals 1.1 — клиентский мод для Minecraft 1.21.4 (Fabric)

Клиентский мод с меню в стиле «читерских» клиентов: боковая панель с логотипом,
поиском и категориями, список модулей и панель настроек справа. У каждого модуля
есть свои настройки — слайдеры, тумблеры, списки и выбор цвета.

## Меню

`Right Shift` — открыть меню.

- Слева: логотип, поле поиска (печатайте сразу после открытия, Backspace — стереть)
  и категории `All modules / HUD / Render / World / Combat / Misc`.
- В центре: список модулей с анимированными переключателями. Клик по строке
  включает модуль и выбирает его.
- Справа: описание и все настройки выбранного модуля.
- Панели скругляются, меню открывается с масштабированием, строки подсвечиваются
  с анимацией, уведомления о включении модуля выезжают снизу справа.
- Панели со списком включённых модулей в HUD больше нет.

## Модули

**HUD**

| Модуль | Настройки |
| --- | --- |
| HUD | FPS, координаты, направление, скорость, пинг, TPS, память, фон, сторона экрана |
| Target HUD | масштаб, показывать дистанцию, полоска здоровья |
| Keystrokes | масштаб, кнопки мыши, пробел |
| Watermark | масштаб |

**Render**

| Модуль | Настройки |
| --- | --- |
| Zoom | FOV при удержании `C` |
| Fullbright | сила (гамма 1–20) |
| Aspect Ratio | произвольное соотношение сторон |
| No View Bob | только от первого лица |
| No Damage Tilt | сила 0–100 % |
| No Nausea | сила 0–100 % |
| No Darkness | сила 0–100 % |

**World**

| Модуль | Настройки |
| --- | --- |
| Custom World | своё время суток (слайдер 0–23999), цвет неба (hue-слайдер), ясная погода |
| Custom Fog | начало и конец тумана, цвет тумана (hue-слайдер), включение цвета |
| Particles | режим `ALL / DECREASED / MINIMAL` |

**Combat**

| Модуль | Настройки |
| --- | --- |
| Kill Aura | радиус 2.5–6, CPS 1–20, взмах рукой |
| Aim Assist | сила 5–100 %, радиус 2–6 |

**Misc**

| Модуль | Настройки |
| --- | --- |
| Auto Sprint | задержка в тиках |
| Fast Place | задержка правого клика |
| Auto Respawn | задержка респавна |
| Death Coords | сообщение в чат с координатами смерти |

Клавиши: `Right Shift` — меню, `C` — зум, `H` — HUD.

## Что и как работает

- **Custom World** меняет только клиентское время и небо: сервер продолжает жить
  по своему времени. Цвет неба (hue-слайдер) перекрашивает всё небо, время
  двигает солнце и луну, «Clear weather» убирает дождь и грозу визуально.
- **Custom Fog** задаёт дистанцию тумана в блоках и его цвет; цвет применяется
  и к туману в мире, и к дальнему фону.
- **Kill Aura** бьёт ближайшего игрока в радиусе через
  `ClientPlayerInteractionManager.attackEntity`, **Aim Assist** плавно доводит
  прицел, пока зажата атака.
- **Fast Place** обнуляет задержку правого клика, **Auto Respawn** жмёт респавн,
  **Death Coords** пишет координаты смерти в чат.

Миксины: `GameRenderer` (аспект), `BackgroundRenderer` (туман: дистанция и цвет),
`World` (время/погода), `ClientWorld` (цвет неба). Аксесс-виденер открывает
`BackgroundRenderer$FogType`.

## Установка

1. **Fabric Loader 0.16.9+** для Minecraft **1.21.4**.
2. **Fabric API** для 1.21.4 в папку `mods`.
3. Собранный `nevvavisuals-1.0.0.jar` в папку `mods`.

## Сборка jar на GitHub

Workflow лежит в репозитории. Запушьте изменения (или нажмите `Run workflow`
на вкладке **Actions**) → дождитесь зелёной галочки → откройте запуск →
**Artifacts** → `nevvavisuals-jar`. Внутри архива готовый
`nevvavisuals-1.0.0.jar`.

Локально (нужен JDK 21):

```bash
chmod +x gradlew
./gradlew build      # Windows: gradlew.bat build
```

## Конфиг

Файл: `.minecraft/config/nevvavisuals.json`

```json
{
  "modules": { "HUD": true, "Target HUD": true, "Kill Aura": false },
  "bools": { "clear_weather": true, "world_sky_tint": false },
  "numbers": { "zoom_fov": 30.0, "world_time": 6000.0, "world_sky_color": 205.0,
               "fog_start": 40.0, "fog_end": 300.0 },
  "choices": { "particles_mode": "DECREASED", "hud_corner": "LEFT" },
  "notifications": true
}
```

Значения пишутся автоматически при любой правке в меню и при выходе из игры.
Цвета хранятся как угол оттенка (0–360).

## Технические детали

Minecraft **1.21.4**, Yarn **1.21.4+build.8**, Fabric Loader **0.16.9**,
Fabric API **0.119.4+1.21.4**, Fabric Loom **1.10.5**, Gradle **8.12**, Java **21**.

```

  gui/NevvaScreen.java  меню: сайдбар, поиск, список, настройки
  hud/                  HUD, Target HUD, Keystrokes, Watermark, уведомления

  module/modules/       все модули
  module/setting/       тумблеры, слайдеры, списки, цвет
  render/               скруглённые панели, градиенты, текст
```

## Замечание

Combat-модули и Fast Place меняют пакеты и на публичных серверах почти всегда
запрещены античитами и правилами. Используйте только там, где это разрешено:
свой сервер, синглплеер или серверы, которые такое допускают.
